# page-native-ads 最终规格合并候选

候选唯一来源为本变更的 [完整目标规格](specs/page-native-ads/spec.md)。当前主规格目录为空，两个在途变更的同名 ADDED 不得顺序盲目同步。旧 `add-page-native-ads` 仅保留历史任务/证据；此文件不执行同步或归档，也不声明所有目标已实现。

## 替代与承接

| 旧 Requirement | 唯一目标 Requirement / 处理 |
| --- | --- |
| 页面卡片显式选择已配置的平台 | 同名，保留单平台与双 ID 源码接入 |
| 请求和挂载遵守页面资格 | 页面资格与共享库存需求分别管理 |
| 身份稳定时不重复创建广告 | 同名，加上策略和 position 配置约束 |
| 页面实例独立拥有资源且销毁不可逆 | 业务位置唯一且不依赖页面实例编号；双策略及最终销毁 |
| 临时隐藏保留页面身份并安全处理媒体 | 销毁和保留两种展示策略行为明确；保留恢复按来源验证媒体与事件 |
| 在途加载和迟到结果按周期隔离 | 在途加载和迟到结果按归属隔离 |
| 状态和重试具有明确边界 | 状态和显式重试具有明确边界 |
| 默认及自定义布局使用同一素材绑定契约 / 无效绑定不得产生部分广告 | 统一只读素材保持平台语义；默认及自定义布局遵守同一完整绑定契约 |
| 素材注册和真实交互由平台负责 | 完整绑定契约及曝光点击关闭和收益保持平台真实语义 |
| TopOn 渲染类型和模板尺寸明确匹配 / 卡片尺寸和披露元素保持可用 | 兼容性检查不以换广告掩盖宿主错误；模板媒体尺寸和披露元素完整可用 |
| 缓存只服务当前卡片且按平台验证有效性 | 由共享库存/有界闲置/原期限替代，不保留“不预取”限制 |
| Compose 包装沿用同一页面资源管理 | Compose 分离组合容器与展示所有权；不再无条件销毁保留记录 |
| Native 不进入全屏展示及竞价流程 / Native 交互不得意外触发自动开屏 / 新格式不改变既有全屏配置和依赖契约 | Native 不改变全屏与基础接入契约 |
| 事件身份独立且页面加载可追溯 / 加载及未曝光终态只收口一次 | 事件身份独立且页面获取可追溯；slotId 保留为业务 position，requestId/sessionId 保留 |
| 曝光点击和关闭保持平台真实语义 / 收益使用真实平台数值并与原广告绑定 | 曝光点击关闭和收益保持平台真实语义 |
| 一个页面请求完成原生比价和渲染 | 同名，加上取货核对与重选有界；能力不支持时实际对象比价 |
| 未展示的落选对象可跨 Activity 复用 | 同名，加上未展示期限不能因迁移或补货重置 |

新增的中文日志与分层能力验收 Requirements 也只保留本变更版本。旧同 position 多实例、固定销毁、永不预取、所有 onRelease 均销毁等限制不再进入合并候选。
