# Ads Mediation SDK 1.0.14

Maven 坐标：`com.cashcraft.sdk:ads-mediation:1.0.14`。

`Ads.showOpen` 的等待预算现在包含 UMP 网络请求及同意流程等待；后台暂停仍不消耗预算。隐私未允许时不得加载或展示广告，等待超时只结束本次开屏机会，晚到回调不会恢复旧机会。插屏及其他展示接口保留原计时策略。

宿主收到超时或无广告结果后自行进入首页；配置的预算不包含进程启动、页面创建及宿主额外跳转延迟。

回归覆盖 UMP 未完成时超时、不加载不展示、晚到回调不能重启、获准后只使用剩余预算，以及后台暂停和插屏原策略。发布通过仓库的 Publish GitHub Package 工作流执行。
